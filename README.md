# Prompt Engineering for Generative AI (1 hour)

Generative AI models can produce impressive content, but vague or poorly structured inputs often yield inaccurate, generic, or hallucinated responses. Without structured prompting techniques, users struggle to obtain consistent, high-quality results from modern AI assistants.

This course teaches foundational prompt engineering principles to bridge the gap between intention and model output. Students learn how to establish context, specify roles and constraints, apply core prompting patterns, and iteratively refine prompts using Google Gemini.
